# 🧱 Streamlit 벽돌깨기 게임

Streamlit과 HTML Canvas, JavaScript를 이용해서 만든 간단한 벽돌깨기 게임입니다.

## 🎮 조작 방법

### PC

- ← : 왼쪽 이동
- → : 오른쪽 이동
- 마우스 : 패들 이동
- Space : 게임 오버 후 다시 시작

### 모바일

화면 아래의 ◀ ▶ 버튼을 이용합니다.

## 🕹️ 게임 방법

공이 벽돌에 부딪히면 벽돌이 사라지고 점수가 올라갑니다.

- 벽돌 1개 = 10점
- 목숨 = 3개
- 모든 벽돌을 제거하면 게임 승리
